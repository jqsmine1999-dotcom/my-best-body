プライバシーポリシー

最終更新日: 2026年10月31日

1. 取得する情報

  • Google アカウントの情報: メールアドレス、名前、Google のユーザー ID（ログインと本人の識別のため）
  • 入力した情報: 性別、生まれ年、身長、体重、目標体重、目標日、活動量、食事の時刻
  • 記録: 食事の内容と推定栄養価、運動の内容と推定消費カロリー、体重
  • 通知の購読情報: 通知を有効にした場合のみ、ブラウザが発行する送信先情報

2. 利用目的

取得した情報は、本アプリの機能（目標の算出、記録の表示、栄養価・消費カロリーの推定、アドバイスの表示、食事の通知）を提供するためだけに利用します。広告や第三者への販売には利用しません。

3. Google ユーザーデータの取り扱い

本アプリが Google から受け取る情報は、OpenID Connect の基本スコープ（openid、email、profile）の範囲に限られます。これらはログインと本人の識別にのみ使い、他の目的への利用、第三者への提供、AI モデルの学習への利用は行いません。本アプリの Google ユーザーデータの利用は、Google API Services User Data Policy（Limited Use 要件を含む）に従います。

4. 外部サービス

  • Cloudflare（Workers・D1・Workers AI）: アプリの実行、データの保存、食事・運動の文章からの推定とアドバイス文の作成に利用します。AI には入力した文章と記録の集計値を送信しますが、メールアドレスや名前は送信しません。
  • Google: ログインに利用します。
  • Apple / Google / Mozilla などのプッシュ通知サービス: 通知を有効にした場合に、通知の配信に利用します。

5. 保存期間と削除

データはアカウントを削除するまで保存します。設定画面の「アカウント削除」から、アカウントとすべての記録を直ちに削除できます。削除したデータは復元できません。

6. Cookie

ログイン状態の維持とログイン処理の安全性確保のため、必要最小限の Cookie（HttpOnly）を使用します。分析・広告目的の Cookie は使用しません。

7. 安全管理

通信は HTTPS で暗号化し、セッション情報はハッシュ化して保存します。他のユーザーのデータにはアクセスできないよう、すべての操作で本人確認を行います。

8. お問い合わせ

本ポリシーに関するお問い合わせは GitHub Issues までお願いします。

9. 改定

本ポリシーを改定する場合は、このページで告知します。
